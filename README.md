# Turbo-Scratch

Play any Scratch project at full speed using [TurboWarp](https://turbowarp.org), right in your browser.

## Features

- **Paste a Scratch project URL or just the numeric ID** — the site figures it out automatically.
- **Embedded TurboWarp player** — faster than the standard Scratch player with hardware-accelerated rendering.
- **Custom controls outside the player:**
  - 🚩 **Green Flag** — restart and run the project
  - 🛑 **Stop** — stop all scripts
  - ⏸ **Pause / Resume** — pause execution mid-run
  - ⛶ **Fullscreen** — native browser fullscreen for the player
- Keyboard shortcut: press **F** to toggle fullscreen while a project is loaded.

## Supported input formats

| What you type | Example |
|---|---|
| Numeric project ID | `10128407` |
| Scratch project URL | `https://scratch.mit.edu/projects/10128407/` |
| TurboWarp project URL | `https://turbowarp.org/10128407` |

## Usage

Open `index.html` in any modern browser, or host it on any static web server / GitHub Pages.

No build step, no dependencies — it's a single self-contained HTML file.
